# Student Registration Application

## Project Overview
A web application that allows users to register student information and store it in a MySQL database.

## Technologies Used
- Python
- Flask
- MySQL
- Docker
- AWS EKS
- Amazon ECR

## Project Purpose
The purpose of this project is to learn how to containerize a web application and deploy it to Kubernetes on AWS.

## Architecture
Local Application → Docker → Amazon ECR → Amazon EKS

## Features
- Student registration form
- Data storage using MySQL
- Docker containerization
- Kubernetes deployment
